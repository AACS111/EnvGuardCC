# EnvGuardCC macOS 阶段零/一结果

本文件保留阶段零、一当时的验收记录；后续进展见 [阶段二、三结果](MACOS-STAGE23-RESULTS.md)。

2026 年 10 月 31 日。记录基于上游 b4d27d5 的源码开发实现；阶段零（关键接入条件）和阶段一（Mac 桌面基础）已完成，阶段二及之后未实施。当前 Mac 实测检出为本仓库工作树，其中包含尚未提交的 Mac 适配；上游 b4d27d5 不包含这些改动。本文只记录实际观察到的结果，未执行的失败、权限和恢复路径不列为通过。

## 结论

- Apple Silicon 上的开发启动、页面与本地服务、受控 Chrome 临时配置、正常退出（含端口释放）和单实例行为已验证。
- 当前交付是源码开发能力，不是可安装的 macOS 发行版：没有构建、签名、公证或分发 `.app`/DMG，也未验证 Finder 实际安装。
- 未测试 Windows 实机和更旧版本的 macOS，因此不声明 Windows 本次通过、最低 macOS 版本或 Intel 支持。
- Mac 代理自动读取、系统时区写入、完整 Claude 桌面端管理和 FlClash 联动仍属后续阶段。

## 已完成验证

### 构建和既有检查

- 14 项应用路径/环境检查和 26 项开发启动/关闭/桌面启动器检查，共 40 项通过。
- 完整 `pnpm lint` 通过。
- 完整 `pnpm build` 通过；保留现有 TypeScript 5.0.2 推荐提示，未升级依赖。
- `classic-level` 3.0.0 在 Node 和 Electron 中均对真实临时数据库完成读写。

### 受控浏览器

Chrome 156.0.8078.76 使用临时用户配置完成实际应用、刷新、恢复和代理验证并通过。验证未使用个人浏览器目录或真实账号请求。本次只记录 Chrome 的同等运行验证，Edge 未单独实测。

### Claude 接入

Claude 4.4212.0 在启动时拒绝 remote-debugging/network override 命令，以退出码 1 结束，未建立 CDP 连接。此次结果只能证明该版本拒绝该启动方式，不能证明客户端受控启动、网络接管或页面接入可用；这些能力未计入完成范围。

### 代理和时区

系统静态代理在 `scutil` 中未启用；本轮只读检查，未修改系统代理或时区。时区保持 `Asia/Shanghai`。后续实现 Mac 代理自动读取时需区分“未启用”“无法解析”“读取失败”；系统时区写入仍待实现，并需真实授权和恢复验证。

### 桌面运行和退出

- `CHECKCC_DESKTOP_SMOKE=1 pnpm dev:electron` 实跑通过：窗口可见、本机助手和网关可连接、渲染进程无 Node 集成，最终退出码 0。
- 发布模式隔离验证使用导出的页面和绝对路径 `runtime/node`，不是打包后的 `.app`。可见界面、服务、样式、导航、对话框和渲染隔离通过。
- 界面触发 `Cmd+Q` 和关闭窗口两条路径均以退出码 0 结束，本次启动的端口得到释放。
- 第二实例以退出码 0 结束，首个实例仍可访问。

### 补充路径与失败验收

以下由 supervisor 执行，不计入前述 40 项自动化检查：

- 3030 被占用时进程以退出码 1 结束，原有测试服务保留，没有 3001/3010 服务残留。
- Next 启动参数无效时以退出码 1 结束，3001/3010/3030 均得到释放。
- 导出目录为空时启动桌面 smoke 以退出码 1 结束并报告工作区错误，未挂起。
- 发布模式隔离验证在 `PATH=/usr/bin:/bin` 下通过：服务、样式和渲染隔离通过，退出码 0。该结果证明运行文件选择使用绝对路径，不是 Finder 安装包测试。
