# 可执行环境配置

重启 `npm run dev` 后，Next、网关和本机助手一起启动。旧的独立 `repair:helper` 若占用 3001 且不支持环境脚本，启动器会提示退出旧助手，不会强制结束用户进程。

选择带“可执行·接口屏蔽”的选项，点击“应用脚本并验证各端”。报告分别显示当前检测页面、独立 Claude 网页窗口、Claude 桌面端；语言/区域还列出网关模拟消息的验证结果。各端均以收到的实际采样为准。

| 项目 | 实际执行方式 |
| --- | --- |
| 字体地区特征、厂商字体 | Canvas/OffscreenCanvas 字体候选过滤，FontFaceSet 与本地字体查询过滤 |
| 语言、文字特征 | navigator 声明与浏览器请求语言覆盖；单一语言同时应用网关 |
| Intl 区域 | 默认 Intl 参数、浏览器 locale 覆盖、网关区域配置 |
| WebRTC | 关闭受控渲染环境的 RTCPeerConnection，可能影响通话 |
| 系统时区、UTC 偏移 | Windows Set-TimeZone，保留原值并核对结果，可能需要系统权限 |
| 国家、城市、ASN、出口类型、DNS 一致性 | 网络观测项；需在 FlClash 或网络侧调整后复测 |
| 真实设备、操作系统、浏览器品牌 | 没有可靠的自动硬件替换脚本，仅比较实际环境 |

字体数量选项只保留实际存在的名单字体，不会创造未安装字体。目标端不能满足所选数量时，不会通过接口验证。

Claude 网页须在启动器打开的独立配置窗口中使用，已有个人窗口不会被接管。桌面端通过显式启动的本机回环调试接口接入。已有实例阻止接入、或当前版本禁用调试能力时，会明确失败；可先正常退出桌面端后重试。接入前已发生的请求不能追溯修改。

保护只覆盖列出的接口，不保证覆盖 CSS/SVG、所有 Worker、原生模块等其他检测方式，也不代表真实风控或账号通过。IP 和系统字体不受此脚本修改；删除系统字体会影响其他应用，且不能可靠达到指定接口效果，因此没有采用卸载字体作为自动兜底。

“撤销浏览器及桌面接口屏蔽”恢复接口、清除 CDP 语言/区域覆盖并重新采样。系统时区另有恢复按钮，网关配置由网关按钮管理。正常停止助手会先撤销桌面页面覆盖再断连；若助手崩溃或应用拒绝恢复，请正常退出对应桌面端后重新打开。

运行 `npm run test:environment` 验证。需要已安装的 Chrome/Edge，或通过 `CHECKCC_BROWSER_PATH` 指定可信 Chromium。测试使用临时配置和无头浏览器，不使用个人会话或真实 Claude 账号。

## 浏览器跟随网关迷惑层

点击顶部“接入并验证浏览器”，或重新开启“迷惑层”。浏览器执行器读取同一网关开关与出口语言、区域配置，应用页面接口保护及实际请求语言覆盖。API 请求由 API 网关转发；受控浏览器的网络继续使用系统代理（如 FlClash）。无需导入 HTTPS 根证书。

首次接入默认屏蔽名单字体、厂商字体及 WebRTC；已有的字体数量配置会保留。浏览器语言列表按网关首选语言、基础语言与英语去重生成，区域与网关目标一致。页面状态分别检查当前仍打开的 Claude 页面指定接口、浏览器真正发送到本机网关接收端的语言头。仅本机页面通过不代表 Claude 页面已验证；页面关闭、离开 Claude、接入失败均显示未验证。

接入后助手持续跟随网关开关和配置；关闭时撤销覆盖，保留目标配置供再次开启。检测页也会同步本页接口和相关卡片证据。网关或助手断连时不保留旧通过结果。使用单项“应用脚本”或“撤销接口屏蔽”会切换为独立脚本模式；可再次点击接入恢复跟随网关。

正常停止服务会恢复桌面页面并关闭启动器创建的独立网页窗口。当前已打开的其他个人浏览器窗口保持各自的网络和接口配置。

## 目标与复测结果

卡片与详情共用实际选项匹配逻辑，分别显示浏览器、客户端是否达到已保存目标。语言文字特征使用实测语言列表比较，字体使用实测名单类别，时区偏移使用实际 UTC 偏移。相同加分不表示相同配置。时区应用、网关应用与接口脚本都会保存目标并刷新采样；关联的语言文字特征、UTC 偏移以及 DNS 结果同步更新。

完成的检测明确区分可判定、无数据、证据不足和失败；尚未执行或配置已失效的项目仍需测试。来源不提供城市、仅一家出口情报、浏览器跨站探测限制等情况不会被伪造成通过。

## 本程序的 DNS 修复

检测到现有 HTTP 代理（含 FlClash 系统代理）时，网关诊断跳过本机对上游目标域名的 DNS 查询，使用和消息相同的 CONNECT 传输验证目标响应，并通过该传输查询 Cloudflare、Google DoH 参考答案。不增加本机目标查询，也不在代理失败时回退直连。

此验证仅覆盖本程序委托目标域名的路径，不证明 FlClash 内部解析一定走远端，也不证明个人浏览器或整台电脑无 DNS 泄漏。系统范围仍应在 FlClash 启用 TUN、DNS 劫持，并确认目标域名规则命中代理。不同 CDN 答案和 fake-IP 不直接判为泄漏。
