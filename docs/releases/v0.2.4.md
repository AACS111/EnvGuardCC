# EnvGuardCC 0.2.4

本版修复 Windows 下 Claude 防护、内核恢复和普通代理之间的相互影响。

## 修复

- 内核重建前确认 Claude 阻断，隧道和出口验证通过后再移除临时阻断；桌面客户端直连规则在内核退出期间继续生效。
- 未安装 Claude 桌面客户端时允许启动浏览器防护，不再因缺少桌面程序而拒绝开启保护。
- 保护失败、取消或关闭后恢复本次新增的系统接管，保留普通 HTTP/SOCKS 代理；不再自动关闭其他代理客户端，也不为 Claude 禁用 Windows 整机 IPv6。
- 时区或浏览器恢复失败时仍尝试恢复网络，保留未恢复配置的原始备份供重试。
- 复用已授权的特权宿主，区分短暂失联与权限失效；防火墙关闭时先请求用户确认，再尝试开启。
- 修复 Windows 无夏令时地区的时区恢复误报，以及宿主清理、客户端路径发现和防火墙有效规则核验问题。

## 升级与保护范围

- 特权宿主有更新时可能需要一次系统授权；后续启动复用现有授权。
- 浏览器在内核恢复期间的阻断依赖 hosts，不覆盖已有缓存连接或独立安全 DNS，不能视为所有浏览器请求的防泄漏保证。
- 切换隧道、节点或底层网络仍可能影响已有连接；本版不保证网络切换时零中断。
