# EnvGuardCC 0.2.7

本版修复同入口多节点切换时的兜底出口故障转移问题，并改进自建节点安装脚本与移动端构建流程。

## 修复与改进

- **兜底出口故障转移**：修复共用同一入口 IP 的多协议节点（如 TCP-Reality 与 UDP-Hysteria2）在首节点超时时，`AUTO-PROXY` 兜底组被降级为无健康检查且固定绑定首节点的问题；现在始终保留 `fallback` 健康检查，并优先使用当前选中的节点。
- **自建节点安装**：修复 Xray / sing-box 安装脚本并支持自定义端口与 nginx 订阅链接。
- **移动端构建**：打标签发布时自动触发移动端构建工作流，产出 Android APK 与 iOS XCFramework 产物。

## 升级说明

Windows 升级后首次启用保护时，可能需要授权更新特权宿主。
