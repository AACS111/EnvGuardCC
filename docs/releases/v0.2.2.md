# EnvGuardCC 0.2.2

## 改进与修复

- 常规网络保护通过独立的 Claude 守卫组切换阻断与放行，减少网络波动时全量重载配置对其他连接的影响；守卫切换失败时保留阻断兜底。
- 完善网络恢复后的自动复检、出口验证缓存与网络变化识别，避免复用已失效的出口证据；IPv6 能力改为后台探测并按有效期缓存。
- 桌面窗口不再等待内核与启动保护全部准备完成，后台就绪后即可显示页面；保护启动时更新受管浏览器，不再自动打开新窗口。
- 改进退出时的任务取消和网络恢复顺序，停止订阅下载、出口探测及定时任务后再回收内核；兼容 Windows 图形界面启动时已关闭的日志管道。
- 修复受管浏览器跨域 iframe 刷新时的脚本执行等待，保留首次页面脚本运行前的语言覆盖，并验证覆盖撤销和重复恢复。
- 连接流向图新增螃蟹随保护开关在网关与出口之间往返跳跃的动画。
- 浏览器 WebRTC 回归使用本地 STUN 服务，并验证开启保护时无候选地址泄露、关闭后可采集候选地址，减少公共服务或 DNS 波动造成的测试超时。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `EnvGuardCC-Setup-0.2.2.exe` | Windows x64 安装程序。 |
| `EnvGuardCC-Windows-x64.zip` | Windows x64 便携版，完整解压后运行。 |
| `EnvGuardCC-0.2.2-arm64.dmg` | Apple Silicon Mac 安装镜像，将应用拖入 Applications 后启动。 |
| `EnvGuardCC-macOS-arm64.zip` | Apple Silicon Mac 应用压缩包。 |
| `SHA256SUMS.txt` | 四个安装文件的 SHA-256 校验值。 |

请先从托盘或应用菜单正常退出旧版，等待原始配置恢复完成，再替换或安装新版本。升级不会自动开启环境防护。

Windows 安装器在系统缺少 WebView2 时联网安装；便携版需先安装 WebView2。Mac 包使用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证，首次打开可能需要在“隐私与安全性”中授权。不提供 Intel Mac 安装包。

## 验证与能力范围

- 发布准备阶段在 macOS arm64 完成 470 项 Node 回归、Rust 原生权限测试、前端生产构建，以及真实 WebView 的 Local/Remote ACL、控件保存和连接流向图冒烟验证。Local ACL 首轮未生成报告，复测通过。
- Windows 和 macOS 安装包由对应平台的 GitHub Actions 构建，四个安装文件齐备并生成校验值后才发布。自动化验证不能替代安装升级、自启动、睡眠唤醒、真实出口切换及系统权限的实机验收。
- 普通代理模式和 Windows 不提供内核崩溃后的独立系统断流。macOS 严格模式会在退出或崩溃后保留阻断，需明确关闭严格模式或使用恢复工具解除；详见[连接保护说明](https://github.com/AACS111/EnvGuardCC/blob/v0.2.2/docs/NETWORK-SAFETY-IMPLEMENTATION.md)。
- 本项目不提供 Claude 账号、订阅或代理节点。检测得分仅用于环境自查，不代表封禁概率，也不保证第三方服务资格或账号结果。
