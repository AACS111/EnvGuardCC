# EnvGuardCC 0.1.3

- 桌面宿主从 Electron 迁移到 Tauri 2，使用系统 WebView，继续内置 Node.js 后台，减少下载与安装体积。
- 保留托盘后台运行、登录启动、自动保护、防休眠、唤醒通知与原生资料回收功能。
- 修复桌面设置桥接初始化时序和 Local/Remote 页面权限，支持设置保存与重启后复用。
- Windows 安装器增加旧版迁移和运行进程检查；旧版运行时要求先正常退出。
- 修复冻结锁文件缺失的依赖下载信息。

## 下载与安装

- `EnvGuardCC-Setup-0.1.3.exe`：Windows x64 安装程序。
- `EnvGuardCC-Windows-x64.zip`：Windows x64 便携版，完整解压后运行。
- `EnvGuardCC-0.1.3-arm64.dmg`：Apple Silicon Mac 安装镜像；从托盘或应用菜单退出旧版并等待配置恢复，将应用拖入 Applications 后启动。
- `EnvGuardCC-macOS-arm64.zip`：Apple Silicon Mac 应用压缩包。
- `SHA256SUMS.txt`：四个安装文件的 SHA-256 校验值。

Windows 需要系统 WebView2，安装器在缺失时联网安装；便携版需先安装 WebView2。Mac 使用 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证，首次打开可能需要在“隐私与安全性”中授权。不提供 Intel Mac 安装包。

## 验证范围

迁移代码已在 Apple Silicon Mac 完成生产打包、签名与 DMG 校验、真实 WebView 启动、桌面设置保存和原生权限边界检查，并安装到 Applications 启动。ESLint、Tauri 回归和 Rust 权限测试通过。完整 Node 回归曾有 Chromium 连接超时，相关文件单独重跑 12 项通过。

Windows 和 macOS 发行包由对应平台 GitHub Actions 构建并执行发布检查；自动检查不代表已完成人工验收所有系统集成场景。旧版升级、自启动、睡眠/解锁以及其他机器上的首次时区授权仍需结合实际环境验证。
