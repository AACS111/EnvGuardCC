# EnvGuardCC 0.1.1

- 增加 Apple Silicon macOS 桌面支持、系统代理读取、连接设置与 FlClash 联动。
- 修复 Mac 开启保护未应用系统时区的问题；修改前保存原始时区和自动时区开关，保护期间关闭自动时区选择，正常关闭或退出时恢复。
- 修复 pnpm 首次启动、打包时误把 pnpm CLI 当作 npm CLI 的问题。
- 使用长期 `develop` 分支进行开发与 PR 集成，`main` 用于稳定发布。

## 下载

- `EnvGuardCC-Setup-0.1.1.exe`：Windows x64 安装程序。
- `EnvGuardCC-Windows-x64.zip`：Windows x64 便携版，完整解压后运行。
- `EnvGuardCC-0.1.1-arm64.dmg`：Apple Silicon Mac 安装镜像，将应用复制到“应用程序”。
- `EnvGuardCC-macOS-arm64.zip`：Apple Silicon Mac 应用压缩包。
- `SHA256SUMS.txt`：以上四个文件的 SHA-256 校验值。

Mac 包使用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证，首次打开可能需要在系统设置的“隐私与安全性”中授权。系统时区修改和恢复需要管理员授权。Intel Mac 不在此次发布范围。

## 验证范围

已在本机 Apple Silicon Mac 验证保护开启、复检和关闭恢复。Emoji 渲染风格取决于系统字体，机房网络出口类型取决于真实代理出口，软件不会将这两项伪报为通过。Windows 由 Actions 构建并运行自动回归，不等同于 Windows 实机完整交互测试。
