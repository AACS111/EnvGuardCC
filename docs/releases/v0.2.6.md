# EnvGuardCC 0.2.6

本版改进网络切换后的保护恢复、规则分流和出口记录。

## 修复与改进

- **网络保护恢复**：改进休眠唤醒、拔插网线或切换网络后的出口网卡识别。隧道和出口验证通过后，才解除临时阻断。
- **Windows 保护开关**：关闭环境保护时保留系统流量接管，其他应用可继续使用代理，同时拦截 Claude。重新开启保护并验证出口后清理 hosts 拦截，自动开启保护的启动过程跳过临时写入。
- **规则分流**：规则模式使用内置国内域名和离线中国 IP 数据分流，Claude 流量继续走专用出口。
- **出口与传输记录**：按实际出口 IP 汇总 Claude 连接和网关请求，支持查看明细和导出。缺少出口证据的记录显示为「出口未知」。
- **桌面兼容性**：改进后台异常退出时的配置恢复，并补齐桌面构建所需的运行时文件。

## 升级说明

Windows 升级后首次启用保护时，可能需要授权更新特权宿主。
