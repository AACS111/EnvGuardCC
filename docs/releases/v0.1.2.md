# EnvGuardCC 0.1.2

- 移除具体代理产品联动和连接设置面板，自动跟随系统代理，保留通用功能。
- macOS 首次授权后绑定受限的时区辅助服务，后续修改与恢复时区复用授权；取消授权后后台不会反复弹窗。
- 增加 Windows/macOS 开机自启动、启动后自动开启保护；关闭窗口保留后台运行，从托盘或应用菜单退出时恢复配置。
- 实时检测开关与检测间隔立即保存到本地，重启应用及关闭再开启保护后仍保留；保存失败不会覆盖当前设置。
- 增加“Claude 恢复初始化”：先关闭保护并退出客户端，确认范围后将支持位置的桌面本地资料移至废纸篓/回收站；部分失败会明确提示。
- Mac 安装镜像增加 Applications 快捷入口及中英文拖拽安装说明。

## 下载与安装

- `EnvGuardCC-Setup-0.1.2.exe`：Windows x64 安装程序。
- `EnvGuardCC-Windows-x64.zip`：Windows x64 便携版，完整解压后运行。
- `EnvGuardCC-0.1.2-arm64.dmg`：Apple Silicon Mac 安装镜像；退出旧版后，将 EnvGuardCC 拖入 Applications，再从“应用程序”启动。
- `EnvGuardCC-macOS-arm64.zip`：Apple Silicon Mac 应用压缩包。
- `SHA256SUMS.txt`：以上四个文件的 SHA-256 校验值。

Mac 包采用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证；首次打开可能需要在系统设置“隐私与安全性”中授权。首次绑定或更新时区服务需要管理员确认，不保存密码。Intel Mac 暂不提供包。

## 数据重置与验证范围

“Claude 恢复初始化”会涉及桌面客户端登录、缓存、设置、MCP 配置与本地 Cowork/桌面会话数据。废纸篓清空前仍可恢复；不会清除云端账号记录、浏览器、Claude Code 或项目文件，不保证解除服务端账号关联。未知存储位置、重定向目录或权限问题会停止或报告，请以实际清理结果为准。

已在 Apple Silicon Mac 实测保护开关、时区授权复用、启动自动保护、窗口后台运行及本地资料重置。Windows/macOS 安装包由对应平台 Actions 构建并执行回归；Windows 自动回归不等同于全部场景的人工交互验证。Emoji 渲染风格和真实网络出口类型仍受系统字体、网络条件约束。
