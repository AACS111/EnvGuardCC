# EnvGuardCC 0.2.5

本版改进 Windows 环境防护启动、特权宿主复用和状态查询的稳定性。

## 修复与改进

- 启动时先确定保护策略，再接管隧道；自动保护失败后仍尝试恢复普通本机代理。
- 改进隧道恢复与 Claude 阻断时序，减少保护切换过程中的误阻断和状态误报。
- 特权宿主按运行包内容识别版本，复用未变化的宿主，减少重复授权；健康检查使用缓存，避免被系统查询阻塞。
- 时区状态改为后台读取，查询失败后自动重试，读取期间避免显示过期的不匹配提示。
- 增加本机请求超时控制、日志限流与轮转，降低后台请求和日志对运行稳定性的影响。
- 固定打包所用 Node 运行时的官方校验值，支持校验本地缓存；改进临时依赖链接不可用时的构建兼容性。
- 更新 browserslist 至 4.28.7，补充环境配置、私钥和本机工具配置的 Git 忽略规则。

## 升级说明

- 本版特权宿主内容有更新，首次使用可能需要一次系统授权。
- 浏览器阻断依赖 hosts，不能保证覆盖已有缓存连接或独立安全 DNS；网络切换也可能中断已有连接。
