# EnvGuardCC 0.2.3

## 修复与改进

- 后台发生未捕获异常或未处理的 Promise 拒绝时，先尝试恢复用户配置并关闭服务，再退出。恢复等待上限为 60 秒，失败时保留原始备份。
- 修复 Claude 代理配置在崩溃后残留本机代理地址的问题，兼容旧版受污染的备份，恢复时避免再次写回已停止服务的端口。
- 桌面后台日志保存到应用配置目录的 `logs/backend.log`，记录启动、配置恢复与退出情况。日志超过 8 MB 时在下次启动轮换。
- 后台异常退出提示增加退出码与日志路径，便于定位和反馈问题。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `EnvGuardCC-Setup-0.2.3.exe` | Windows x64 安装程序。 |
| `EnvGuardCC-Windows-x64.zip` | Windows x64 便携版，完整解压后运行。 |
| `EnvGuardCC-0.2.3-arm64.dmg` | Apple Silicon Mac 安装镜像，将应用拖入 Applications 后启动。 |
| `EnvGuardCC-macOS-arm64.zip` | Apple Silicon Mac 应用压缩包。 |
| `SHA256SUMS.txt` | 四个安装文件的 SHA-256 校验值。 |

请先从托盘或应用菜单正常退出旧版，等待配置恢复完成，再安装或替换应用。

Windows 安装器在系统缺少 WebView2 时联网安装，便携版需要已安装 WebView2。Mac 使用 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中授权。
