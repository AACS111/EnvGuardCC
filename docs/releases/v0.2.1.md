# EnvGuardCC 0.2.1

## 新功能与改进

- 新增内置 mihomo 网络工作台：管理自己的订阅、配置文件、手工节点和本机代理，支持测速、实际出口检测、代理范围切换及内网豁免。
- 新增连接流向图、传输记录和出口稳定性视图，区分代理、直连与已拦截连接；观测结论仅覆盖内核采样到的流量。
- 完善系统流量接管、网络异常自动复检、宿主协议协商和代理设置迁移；macOS 提供可选的严格连接保护。
- 左下角新增“检查更新”：启动后检查 GitHub 最新正式版本，运行期间每 6 小时复查，也可手动检查。有匹配平台安装包时显示“可更新”，提供版本说明和下载入口。
- 更新说明支持 Markdown 标题、列表、代码、链接、引用及 GitHub 风格表格和任务列表；不执行原始 HTML 或危险协议链接。
- 修复保护流程中的受管浏览器同步，并在同一保护会话采样前同步浏览器状态。
- 改进 BIGLOBE 等网络组织识别；只用同 IP、同 ASN 的其他情报源补充缺失或注册局名称，保留住宅、机房和未知三态及原始证据。
- 更新中英文 README、界面截图、操作说明和常见问题；改进 macOS 打包时临时目录清理的容错。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `EnvGuardCC-Setup-0.2.1.exe` | Windows x64 安装程序。 |
| `EnvGuardCC-Windows-x64.zip` | Windows x64 便携版，完整解压后运行。 |
| `EnvGuardCC-0.2.1-arm64.dmg` | Apple Silicon Mac 安装镜像，将应用拖入 Applications 后启动。 |
| `EnvGuardCC-macOS-arm64.zip` | Apple Silicon Mac 应用压缩包。 |
| `SHA256SUMS.txt` | 四个安装文件的 SHA-256 校验值。 |

请先从托盘或应用菜单正常退出旧版，等待原始配置恢复完成，再替换或安装新版本。安装后点击左下角“检查更新”可查看当前版本。升级不会自动开启环境防护。

Windows 需要系统 WebView2，安装器在缺失时联网安装；便携版需先安装 WebView2。Mac 包使用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证，首次打开可能需要在“隐私与安全性”中授权。不提供 Intel Mac 安装包。

## 使用与验证范围

- 本项目不提供 Claude 账号、订阅或代理节点。检测得分仅用于环境自查，不代表封禁概率，也不保证第三方服务资格或账号结果。
- 普通代理模式和 Windows 不提供内核崩溃后的独立系统断流。macOS 严格模式会在退出或崩溃后保留阻断，需明确关闭严格模式或使用恢复工具解除；详情见[连接保护说明](https://github.com/AACS111/EnvGuardCC/blob/v0.2.1/docs/NETWORK-SAFETY-IMPLEMENTATION.md)。
- 新增更新检查、Markdown 渲染与网络类型识别的回归验证；Windows 和 macOS 安装包由对应平台的 GitHub Actions 构建，四个安装文件齐备并生成校验值后才发布。
- 本地真实 Chromium 环境测试仍出现 ICE 采样超时；macOS 桌面自动启动验证此前未生成报告，这两项不计入已通过的验证。安装、自启动、睡眠唤醒和系统权限等能力仍需结合对应机器实测。
